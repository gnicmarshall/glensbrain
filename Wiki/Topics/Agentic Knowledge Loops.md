# Agentic Knowledge Loops

Using AI agents in a loop to turn raw captures into organised, linked knowledge — the idea this vault is built on (Inbox → Raw → Wiki → Outputs, with a librarian agent doing the filing).

## Key points
- Glen saved a Google Drive folder on this topic on 13 Sep 2026; its contents haven't been read into the vault yet, so this page holds only the link and the concept.
- The vault's own implementation of the idea: see the librarian rules in `_system/LIBRARIAN.md` and the [[Glens Brain]] project page.
- The pattern's core rules from public write-ups (Karpathy's "LLM wiki", 2026): raw sources are immutable, the agent owns the wiki, every page has aliases so nothing gets duplicated, updates are scoped not global, and human edits are never overwritten.
