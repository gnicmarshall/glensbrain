# Inbox

Drop anything here: a thought, a link, a pasted chat, a photo of a whiteboard.
Don't name it well, don't tag it, don't file it. The librarian empties this
folder every couple of days (or run `/brain` in Claude Code to do it now).

What happens to each note: the verbatim text is kept in `Raw/` (dated), the
knowledge in it is written into or merged into `Wiki/` pages, and a line is
added to that run's log in `_system/log/`.

This README is the only file that stays here.
